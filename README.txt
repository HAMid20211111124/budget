ساخت APK با GitHub Actions (بدون Android Studio):
۱) در github.com یک مخزن (Repository) جدید بسازید.
۲) همه فایل‌های این پوشه (از جمله پوشه مخفی .github) را در ریشه مخزن آپلود کنید.
۳) تب Actions > Build APK > پس از سبز شدن، فایل SmsBudget-APK را از پایین صفحه دانلود کنید.
۴) فایل zip را باز کنید و app-debug.apk را روی گوشی نصب کنید.
